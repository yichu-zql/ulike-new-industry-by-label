# ulike-new-industry-by-label

正式地址：https://yichu-zql.github.io/ulike-new-industry-by-label/

基于久谦商品月表的家用医疗设备研究。研究医用压缩式雾化器、医用分子筛制氧机；排除专业人员操作的院用设备。纳入、排除和待确认分别保留。覆盖2023年1月至2026年9月，2026年不是完整年度。

## 页面与数据

- `index.html` / `styles.css` / `app.js`：静态界面，规模与趋势、品牌、商品打标三个视图。
- `metrics.js`：统一筛选、汇总和CSV导出规则。
- `data-client.js`：gzip优先，JSON兼容回退，按需加载及会话缓存。
- `data/manifest.json`：数据截止、源端入库时间、采集时间、标签版本及内容哈希分片。
- `data/summary.*`：首屏年月汇总；品牌、商品按品类和年份懒加载。
- `tests/`：年度/月度、品牌去重、商品明细、跨平台、缺失月份、哈希和CSV检验。
- `pipeline/`：私有环境执行的只读采集、规则、精确型号复用、标签缓存和网站分片构建；源代码不包含凭据。

商品视图按标题组展示，同一商品的历史标题可能形成多个组，不等同SKU数。金额按当前时间、平台筛选；品牌份额的分母为已纳入GMV。未知品牌不参与成交品牌计数。原始宽类目商品覆盖核验不能解读为目标细分类目覆盖率。

## 限制与更新

商品样本存在截断迹象，尤其京东每类每月500条。本页不是完整行业规模；待确认金额不计入纳入规模。标题及同型号证据不等于逐项注册验证。GMV沿用已有项目退后口径，源表没有退款字段，本次未获源方再次确认。

本版本为固定快照，未配置自动更新。更新应从私有采集环境生成候选数据，校验后复制有效哈希分片并最后更新manifest。数据库连接、原始事实表、原始缓存和凭据不得提交。保留历史快照与上一版本，使用git revert回滚，不重写历史。新增类别须扩展识别规则并验证，不仅改页面名称。

本机更新入口：`pwsh -File pipeline/run.ps1 -ConnectionConfig '本机DPAPI配置.xml' -Refresh`，随后运行`python pipeline/build-site-data.py`、`npm run check`。配置结构沿用当前用户私有连接，保存在仓库外；Python与PyMySQL路径从私有配置读取。未传`-Refresh`时复用成功快照，不代表数据源已更新。每次刷新仍扫描候选范围全量，不宣称数据库增量采集。缓存指纹包含规则、型号字典与分类代码，变化后自动重算，不对每条商品调用LLM。

## 验证与发布

Node.js 22+，无需安装生产依赖。`npm run check`执行语法及数据测试；`npm run serve`本地预览端口8766。GitHub Actions自动校验。Pages沿用main分支根目录部署，保留`.nojekyll`。发布后需核对提交对应的部署、线上manifest及桌面/移动布局、筛选、详情返回和CSV导出。

v1.0.0 / 2026-11-04：首次发布。


v2.0.0 / 2026-11-04：按用户口径，标题含家用直接纳入（明确非目标、配件、专业操作仍排除）；标准型号统一大小写、连字符、欧姆龙NE前缀与鱼跃403后缀，同品牌同标准型号复用家用证据。混合链接按来源类目、月份、平台独立保留，金额不拆分；占比分母为纳入＋待确认候选金额。此前版本仍可通过Git提交回溯。
关联补充：同平台、商品ID、店铺和品牌的历史标题复用家用证据；存在明确排除历史的链接不自动继承。同标题组涉及多条链接时须全部具有合格关联。


v3.0.0 / 2026-11-04：按待确认GMV优先核查。补齐PARI文本型号、可孚完整/简写型号和YDD多型号省略前缀；补充可孚及PARI官方资料。标准型号可作为历史链接的家用证据；网式型号与明确非目标历史沿精确链接纠正归类。排除储雾罐、检测仪、口腔清新喷雾、氢氧、熏蒸及户外电源等错归商品。标签主键新增平台、商品ID和店铺ID，使同名/空标题的不同链接独立判定；不涉及用户持久化内容迁移。

网页新增剩余原因及v2→v3状态金额变动。`pipeline/build-site-data.py`在私有环境存在`label-cache-before-v3.json`时生成前后对照；缺少该快照不声称有可比变化。Excel包含月度明细（3平台、48个月、两个品类，未来缺失保留空白）和年度去重品牌数，以及类目销售额与占比三页；`downloads/medical-category-v3.xlsx`是本次同版本导出。

Excel复用入口：`scripts/export-workbook.mjs`读取当前发布manifest和summary。需使用捆绑Artifact Tool运行时，在导出前执行制表标记脚本；导出后验证三张表与当前分片一致。

原类目对比：行业表同原始久谦三级类目GMV为分母，商品表同类目内已纳入GMV为分子，跨类目补充单列。年度行业GMV及类目内外打标金额均按自然月合计；商品截断限制使比例不能直接等同完整目标行业份额。
